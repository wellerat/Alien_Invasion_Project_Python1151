# Alien Invasion - Track 1: Custom Game Mechanics

## Overview

This project is based on the Alien Invasion game from Python Crash Course by
Eric Mattes.  For the final prject, I selected Track1: Custom Game Mechanics.

The goal of this project is to create new weapon systems and gameplay mechanics.

## Mileston 1 Features

The following features have been completed for Milestone 1:

- Standard Shot weapon - "Basic"
- Double Shot weapon - "Power"
- Spread Shot weapon - "Ultimate"
- Select the weapons using the keyboard
- Added Arsenal class for weapon management
- Modified bullet behavior to support multiple firing patterns

Controls
--------

Left arrow -> moves ship to the left
Right arrow -> move ship to the right
Spacebar -> shoots bullets at aliens
1 -> Select the standard or Basic shot
2 -> Select the double or Power shot
3 -> Select the spread or Ultimate shot

## Project contains:

alien_invasion.py -> main game controller and game loop
ship.py -> Player ship functionality
bullet.py -> Projectile behavior and movement
aresenal.py -> Weapon selection
alien.py -> Alien functionality
settings.py -> Game settings
